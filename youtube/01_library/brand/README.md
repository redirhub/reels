# Brand (channel)

Tokens, fonts and logo marks are code in the reels repo and mirrored from `redirhub/marketing`:

- `src/remotion/brand/tokens.ts` — brand colors (`color.*`) and the channel tokens (`yt.*`: Night,
  Signal Red, teal, amber, blue, inks, glass). Night and Signal Red pending Kris's approval.
- `src/remotion/brand/fonts.ts` — Plus Jakarta Sans (added 2026-10-06, OFL, `public/fonts/`),
  JetBrains Mono, Inter (product UI only).
- `src/remotion/brand/Logo.tsx` — official lockup and icon, color and all-white variants. Never
  redrawn, never recolored.
- Shared video components: `src/remotion/components/` (BrowserCard, UrlPill, RedirectLine,
  GlassCard, Padlock, IdCard, ChecklistBadge, FixedEndCard, OnScreenText).
